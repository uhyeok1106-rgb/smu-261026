단계별 실습

한 단계를 끝낼 때마다 했어요 버튼을 누르세요. 위쪽 진행 바가 채워집니다.

0

파일 확장자 보이게 하기

3분
  1. 파일 탐색기를 엽니다. (Windows 키 + E)
  2. 보기 → 표시 → 파일 확장명을 체크합니다.

💡 이걸 안 하면 index.html.html처럼 이름이 꼬이는 실수가 자주 생깁니다.

1

올릴 파일 준비하기

15분
  1. Artifact 옆 창에서 다운로드를 누릅니다. (안 보이면 ⋯ 메뉴)
  2. 파일 이름을 정확히 index.html로 바꿉니다. 전부 소문자, 띄어쓰기 없이 씁니다.
  3. 파일을 더블클릭해서 브라우저에 화면이 나오는지 확인합니다. (리허설)

⚠️ 하얀 빈 화면이 나오면 React 형식입니다. 템플릿 B로 순수 HTML 한 파일로 다시 받으세요.

💡 내 PC에서 안 열리는 파일은 인터넷에서도 안 열립니다.

2

저장소 만들기

10분
  1. github.com 오른쪽 위 + → New repository를 누릅니다.
  2. Repository name에 my-first-page를 적습니다.
  3. Public을 고르고, Add README를 켭니다.
  4. Create repository를 누릅니다.

✅ 주소창이 github.com/내아이디/my-first-page이면 성공입니다.

3

파일 올리기 = 첫 번째 커밋

10분
  1. Add file → Upload files를 누릅니다.
  2. index.html을 점선 상자에 끌어다 놓습니다.
  3. 메시지 칸에 첫 페이지 올리기를 적고 Commit changes를 누릅니다.

💡 커밋 = 저장 버튼 + 메모. 게임의 세이브 포인트처럼 언제든 이 시점으로 돌아올 수 있습니다.

4

GitHub Pages 켜기

10분
  1. 저장소 위쪽 Settings 탭을 누릅니다.
  2. 왼쪽 메뉴 Pages를 누릅니다.
  3. Source는 Deploy from a branch, Branch는 main과 / (root)를 고릅니다.
  4. Save를 누릅니다.
5

내 주소로 접속하기

10분
  1. 1~3분 기다립니다. Actions 탭에서 🟡이 ✅로 바뀌는지 봅니다.
  2. Settings → Pages를 새로고침하고 Visit site를 누릅니다.
  3. 주소를 휴대폰으로도 열어 보고, 짝꿍에게 보내 봅니다.

✅ 내 페이지가 열리면 성공입니다! 🎉

6

고쳐서 다시 올리기 — Git의 진짜 힘

20분
  1. Claude에게 템플릿 C로 수정을 요청하고, 새 index.html을 받습니다.
  2. 같은 이름으로 다시 업로드하고, 배경색 변경처럼 메시지를 적어 커밋합니다.
  3. 1~3분 뒤 Ctrl + F5로 확인합니다.
  4. 🕒 Commits를 눌러 빨간 줄(지운 것)과 초록 줄(넣은 것)을 비교합니다.

💡 이것이 버전 관리입니다. 본과정에서 5명이 한 코드를 함께 고칠 수 있는 이유입니다.
